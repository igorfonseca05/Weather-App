# Weather Application usando JavaScript ☁️🌧️☀️
Este projeto foi desenvolvido com o objetivo principal de proporcionar aos usuários a possibilidade de acessar informações climáticas em tempo real de qualquer local do planeta. A ideia é oferecer uma ferramenta prática e funcional que permita consultar dados atualizados sobre o clima de forma rápida e eficiente.

Além disso, o projeto tem como propósito secundário, mas não menos importante, servir como um exercício de aprendizado e aperfeiçoamento no uso de JavaScript assíncrono. Isso inclui a prática de realizar requisições a APIs externas, tratar respostas assíncronas e lidar com dados de forma dinâmica, contribuindo para o desenvolvimento de habilidades essenciais em programação web moderna.

### Funcionamento básico
O aplicativo foi desenvolvido para que o usuário insira o nome de uma cidade na barra de pesquisa central do aplicativo. Após digitar, basta pressionar ENTER para obter as informações sobre o clima da cidade pesquisada.

Um diferencial importante é que os dados da última cidade pesquisada são armazenados em cache na memória do navegador. Isso significa que, ao acessar o app novamente, não será necessário buscar pelas informações da mesma cidade repetidamente, pois o navegador recuperará esses dados automaticamente para você, tornando a experiência mais rápida e conveniente.
